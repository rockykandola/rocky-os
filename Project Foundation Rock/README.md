# Project Foundation

Project Foundation is a lightweight, local-only browser dashboard for Rocky's 40–65 day reset, business-building period, and hair-sourcing expedition.

## Run it

Open [`dashboard/dashboard.html`](dashboard/dashboard.html) in a browser. No install, server, account, or internet connection is required.

The app stores entries in this browser's `localStorage`. Use **Export backup** regularly to save a JSON backup on the laptop. Use **Import backup** to restore one.

## First setup

1. Open the dashboard.
2. Day 1 is now set to August 20, 2026 from the supplied booking confirmations. Change it only if the ticket changes.
3. Set the budget assumptions and exchange rates.
4. Replace the sample quote and meditation with the day's own entries.
5. Use the daily check-in and evening review each day.

## Budget assumptions in the first version

- Travel: target $1,500–$2,000 total, using points and SmartFlights where possible.
- Lodging: $35–$45/night.
- Food: $10–$15/day.
- Bikes/cars: $400/month.
- Wellness: approximately $10/class.
- Inventory: $4,000–$8,000.

These are planning targets, not financial advice. The dashboard keeps travel, living expenses, transport, wellness, inventory, and extras separate.

The booked-trip reconciliation currently includes the supplied ticket evidence. Review [`travel/cost-reconciliation.md`](travel/cost-reconciliation.md) and [`travel/itinerary.md`](travel/itinerary.md) for open lodging, baggage, and return-flight items.

The current model also includes hosted-lodging scenarios, Marriott points as a Budapest fallback, a reported Amex 35% points rebate, the reported Merrill Lynch multiplier for the Chiang Mai ticket, aisle-seat preference, and a flexible Myanmar/Cambodia/Vietnam search window before India.

The Aug 15–18 Mobile, Alabama visit is intentionally treated as part of the reset mission—not as travel noise—because it is a surprise visit with Rocky's parents during a period of significant health concern.

## Important boundary

The app is intentionally simple and not a secure system. It is designed for one person on a personal laptop. It does not provide medical, immigration, customs, legal, or safety advice.
